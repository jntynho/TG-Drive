# توقف الاتصال بعد إدخال بيانات API

## الخلل الذي أُصلح في 0.1.1

كانت النسخة السابقة تعالج كل تحديث TDLib في coroutine منفصلة. يمكن أن تُرسل المكتبة حالة `AuthorizationStateWaitPhoneNumber` قبل أن تُرجع نتيجة طلب `SetTdlibParameters`. عند استكمال coroutine التهيئة، كان التطبيق يكتب `CONNECTING` فوق حالة `PHONE` الأحدث. النتيجة: تبقى شاشة الاتصال بدل إظهار إدخال رقم الهاتف، رغم تقدم حالة المكتبة نفسها.

أُعيد إنتاج ذلك باختبار نقل وهمي لا يتصل بتيليجرام؛ فشل الكود السابق بالنتيجة `expected PHONE but was CONNECTING`. في 0.1.1 تُعالج التحديثات بالترتيب، ولا تكتب نتيجة التهيئة المتأخرة حالة اتصال فوق حالة مصادقة أحدث. يغطي الاختبار كلا ترتيبي وصول نتيجة الطلب وتحديث رقم الهاتف.

الإصلاح يتضمن أيضًا:

- إظهار فشل تهيئة المكتبة أو قاعدة بياناتها كخطأ دائم، مع إعادة المحاولة وتعديل بيانات API.
- مهلة 30 ثانية للتهيئة والطلبات العادية حتى لا تبقى أدوات الدخول معطلة دون تفسير. للتنزيل الطويل مهلة منفصلة.
- عرض حالة الشبكة التي تبلغ عنها TDLib، بدل افتراض أن كل انتظار يعني وجود اتصال بالخادم.
- إعادة المحاولة بطلب حالة المصادقة الحالية، دون إنشاء عدة عملاء فوق قاعدة البيانات نفسها.
- إغلاق العميل القديم بـ `Close` عند تعديل بيانات API؛ دون `LogOut` أو `Destroy` ودون حذف ملفات أو قاعدة بيانات.
- تجاهل التحديثات المتأخرة من العميل المغلق وإخفاء قيمة API hash من رسائل الخطأ.

هذا يصلح خلل التطبيق المثبت؛ لا يثبت أن اتصالًا بعينه يعمل على كل شبكة أو أن بيانات API مقبولة لدى خوادم Telegram.

## على الهاتف

1. ابنِ آخر commit على `main` من GitHub Actions، أو ثبّت APK التجربة الجديد. تأكد من عرض الإصدار **0.1.1**. استخدم نفس هوية التوقيع لتحديث النسخة القديمة مع الاحتفاظ ببياناتها.
2. افتح التطبيق. بيانات API المحفوظة تُستخدم تلقائيًا. يفترض ظهور إدخال رقم الهاتف، أو خطأ واضح خلال مهلة التهيئة؛ لا تُحذف الملفات لإصلاح الشاشة.
3. عند ظهور خطأ، استخدم **إعادة محاولة الاتصال**. إذا أشارت الرسالة إلى بيانات التطبيق، استخدم **تعديل بيانات API** وأدخل بيانات التطبيق المسجلة في `my.telegram.org/apps`، وليس bot token.
4. إذا كانت الحالة «ينتظر اتصالًا بالشبكة»، تحقق من اتصال الهاتف وإمكانية الوصول إلى تيليجرام من شبكتك. نجاح إدخال API ID/hash أو ظهور شاشة الهاتف لا يثبت نجاح الوصول إلى الخوادم.
5. إذا استمرت المشكلة، أرسل نص الخطأ أو صورة مقصوصة لا تظهر بيانات API، مع إصدار Android ورقم إصدار TG Drive. لا تشارك API hash أو رموز الدخول أو كلمة مرور التحقق بخطوتين أو ملفات الجلسة.

إن كانت هوية توقيع APK مختلفة عن النسخة المثبتة، فلن يقبل Android تحديثها مباشرة. لا تحذف النسخة القديمة لمجرد مشكلة الاتصال؛ جهّز تحديثًا بنفس مفتاح التوقيع أولًا.

بعد إدخال الهاتف، Telegram يحدد طريقة إرسال رمز الدخول. قد يرسله داخل تطبيق Telegram؛ **وصول SMS غير مضمون**. اختبارات التهيئة لا تحل محل اختبار الدخول بحساب حقيقي، ولم تُستخدم بيانات حساب المستخدم أثناء تطوير هذا الإصلاح.
