# مراجعة UI/UX Pro Max والإصلاحات المحلية

المراجعة تبدأ من `MainActivity` و`NativeApp` وتغطي الصفحات التي يصل إليها المستخدم فعليًا: تسجيل الدخول، فتح المكتبة، Home، الملفات، Gallery، Audio، المعاينات، Activity، Backups، Settings والنوافذ. صفحة `ConnectionsPage` والواجهة القديمة `DriveScreen` ليستا جزءًا من التنقل الحالي؛ لن نعيد إظهارهما.

المهارة: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill، نُزّلت خارج التطبيق في `/workspace/tools/ui-ux-pro-max-skill`. قُرئت `SKILL.md` ومراجع Android/Jetpack Compose وقواعد اللمس والوصول والتباين. الإرشادات تخص توصيات؛ لم تُعتمد نتائج البحث العامة الخاصة بصفحات الويب أو خطوط Google أو GSAP. التطبيق يبقى Kotlin/Compose، إنجليزيًا، داكنًا وبلا اعتماد تشغيل جديد.

الملاحظات التالية ناتجة عن مراجعة المصدر والواجهات التي يمكن الوصول إليها، ثم تطبيق إصلاحاتها محليًا. مراجعة المصدر والاختبارات لا تعني اكتمال فحص جهاز حقيقي أو TalkBack أو قياس الإطارات.

## حدود العمل

لا ترقية عشوائية للمكتبات أو تبديل الهوية أو إضافة واجهات محذوفة. التحسينات تحافظ على التنقل الرباعي وعلى الشبكة 4:5 وزوايا Gallery المستقيمة. لم تُفحص أجهزة/حسابات Telegram حقيقية بعد؛ سيُوثّق ما تنفذه الاختبارات المحلية فعلًا وما يحتاج جهازًا.

ملاحظة بحث: لم ينتج بحثان لنمط التصميم الشامل توصية مناسبة لتخطيط تطبيق Android؛ كانت النتيجة موجهة إلى صفحات تسويقية. استُبعد هذا الجزء وحُوفظ على توكنات التطبيق. توصيات اللمس وحفظ الحالة ودورة الحياة جاءت من نتائج UX وJetpack Compose المناسبة.

## الملفات الأساسية

- البداية والقفل وتسجيل الدخول: `MainActivity.kt` و`StartupPanels.kt` و`DriveScreen.kt`.
- الهيكل والحقول: `NativeApp.kt` و`DriveAppHeader.kt` و`DriveComponents.kt`.
- المكتبة والصور المصغرة: `LibraryUsageCard.kt` و`LibraryPages.kt` و`FilesPage.kt`.
- الوسائط: `NativePreview.kt` و`AudioTransportControls.kt` و`GalleryZoomImage.kt` و`GalleryVideoPlayer.kt`.
- النوافذ والأمان والإعدادات: `FileDialogs.kt` و`PrivacyPages.kt` و`SettingsPage.kt` و`ActivityPages.kt`.

لا تغيير لمفتاح التوقيع أو صيغة بيانات Telegram، ولا إضافة اعتماد تشغيل. ملفات المهارة تبقى خارج المستودع.

## التحقق المنفذ

- اكتمل فحص Debug وRelease المتسلسل: **128 اختبارًا لكل منهما، دون فشل أو تجاهل**؛ أضيفت 12 حالة تحقق مقارنة بالخط الأساسي 116.
- نجح `assembleDebug` و`assembleDebugAndroidTest`. بناء حزمة اختبارات الجهاز ليس تشغيلًا لها على هاتف.
- نجح `lintDebug`: صفر أخطاء و30 تحذيرًا (نفس عدد التحذيرات في خط الأساس قبل هذه المراجعة).
- قياسات تباين ألوان النص الفعلية: الأساسي على البطاقة 11.31:1؛ الثانوي 6.00:1؛ الثانوي على أعلى سطح 4.83:1؛ الرابط 5.60:1؛ النص الأبيض على زر الإجراء 5.27:1؛ الخطأ 7.26:1. هذه قياسات الأزواج المذكورة وليست شهادة لكل محتوى صورة أو فيديو.
- اختبارات UI تشمل الحفاظ على مسودة الهاتف دون حفظ رمز الدخول، منع الإرسال المتكرر عبر IME، التحقق المحلي من API، إخفاء المجلدات المقفلة، تعطيل خيارات الحفظ المتعارضة، seek الصوت عند الحدود، إيقاف الصوت أثناء buffering، فلاتر Gallery وHome على عرض 320dp وخط 200%، والقفل بعد فشل المصادقة.
- اختُبر تسجيل الدخول أيضًا بوضع أفقي 640×360dp وخط 200% مع الوصول إلى الحقول وزر المتابعة بالتمرير.
- في محاولة شاملة سابقة، تجاوز اختبار نقل موجود مهلة 5 ثوانٍ. نجحت فئة اختبارات النقل منفردة ثم نجح الفحص الشامل بتشغيل متسلسل؛ لم يُعدّل اختبار النقل أو تُضعف تأكيداته أو تُغيّر آلية الرفع.
- معاينات Compose محلية ببيانات تجريبية، لا صور هاتف ولا دليل على سرعة Telegram.

أمر التحقق النهائي:

```sh
./gradlew --max-workers=1 testDebugUnitTest testReleaseUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

## ما يحتاج اختبار جهاز

TalkBack الفعلي، تغيير مقياس حركة النظام أثناء العرض، إيماءات أطراف الشاشة، لوحة مفاتيح النظام مع كل نافذة، المصادقة البيومترية/تبديل إعداد أمان الجهاز، جودة الصوت والفيديو الحقيقيين، أذونات موفري الملفات وأداء الإطارات. تمت إضافة الدلالات ومسارات الحركة في المصدر وتجميعها، ولم يُدّع تشغيل فحوص الهاتف هذه محليًا.

تُضمّن هذه التغييرات في إصدار 0.10 مع إصلاحات الرفع بطلب المستخدم اللاحق؛ لم تُبدّل أيقونة Aero Fold الحالية.

نسخة المهارة التي تمت مراجعتها: `d14efff`. لم تُثبت داخل التطبيق، ولم تُشغّل أوامر تثبيت npm أو تغيير النظام.

## ترتيب الأهمية

1. الخصوصية والتعطيل: إحصاءات الملفات المقفلة، اختيار المجلدات، رسائل القفل والأفعال المتعارضة.
2. الوصول والاستخدام: المسودات، لوحة المفاتيح، الخط الكبير، التحكم بالصوت، وأدوات الصور والفيديو.
3. الاتساق البصري: Home المختصر، ألوان الأفعال، البحث والعناوين واتجاه الحركة.

معاينات المراجعة المحلية محفوظة خارج المستودع في `/workspace/reports/tg-drive-ui-review/screens/`. تستخدم بيانات تجريبية ولا تتصل بحساب Telegram؛ لذلك تعرض بعض الصور المصغرة الرموز الافتراضية. هذه ليست صورًا مولّدة لتسويق ميزات غير موجودة.
