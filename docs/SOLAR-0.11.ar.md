# التصميم المعتمد — 0.11

طُبّقت معاينة Dashboard ذات نصف الدائرة ومعاينة Activity ذات قائمة الفلترة الصغيرة، مع أيقونات Solar Linear التي اختارها المستخدم.

## الأيقونات

- استُبدلت المجموعة السابقة بـ **Solar Linear من 480 Design** في جميع مكونات الواجهة، بما فيها تسجيل الدخول والتنقل والمعرض والوسائط والإعدادات والنوافذ.
- 71 رسمًا أصليًا و79 اسمًا وظيفيًا في `DriveIcons`، بمتجهات Compose محلية. لا تحميل أيقونات من الشبكة ولا مكتبة تشغيل إضافية.
- Home: `home-2`؛ Gallery: `gallery`؛ Audio: `music-notes`؛ Settings: `settings-minimalistic`.
- أيقونة الأغنية في التنقل تختلف عن رمز مستند صوتي. اختيرت رموز الملفات والصور والفيديو والأرشيف والمجلدات والإجراءات حسب الوظيفة.
- مصادر SVG المحددة والترخيص ونسبة العمل إلى المصمم في `third_party/solar`، مع روابط المصمم وترخيص CC BY 4.0 داخل About TG Drive.
- يُعاد التوليد دون شبكة بواسطة `python3 scripts/generate_icons.py`. يحتفظ التحويل بأشكال SVG وخصائص الرسم الأصلية. شعار Aero Fold وأيقونة تثبيت التطبيق مستقلان عن مكتبة رموز الواجهة.

## Dashboard

- نصف دائرة مقسّم حسب أحجام الصور والفيديو والصوت وبقية الملفات، مع الحجم الإجمالي في الوسط.
- مفتاح ألوان وحجم لكل نوع، وعدد الملفات وحجم النسخ المحلية أسفل البطاقة، وزر Add files مستقل بعرض الصفحة.
- النسب تمثل توزيع المكتبة المرئية، وليست حدًا أو حصة تخزين على Telegram. يمكن الضغط على البطاقة لقراءة تفاصيل الحساب.
- تبقى الملفات المحذوفة والإصدارات السابقة والخزن المقفلة خارج الإجمالي. حالة المكتبة الفارغة لا تعرض نسبة استخدام وهمية.
- يتكيف الرسم والنصوص والمفتاح مع الخط الكبير بدل تداخل النص مع نصف الدائرة.

## Activity

- قائمة `All transfers` صغيرة: All / Active / Done / Failed، بدل شريط الفلاتر الكبير.
- الأعداد بجانب عناوين الأقسام، وإجراءات البدء والاستئناف وPause all داخل قائمة الرأس ⋮.
- بطاقات مجمعة للعمليات الجارية والمنتظرة والمتوقفة والتي تحتاج تدخلًا والمكتملة والملغاة؛ صفوفها كسولة التحميل حتى مع تاريخ كبير.
- ترتيب الانتظار حسب الأولوية ثم وقت الإنشاء، ومكتمل اليوم منفصل عن الإكمال الأقدم وفق اليوم المحلي للجهاز.
- تقدم الرفع وسرعته وحجمه، إيقاف مباشر لكل عملية جارية، وقائمة سياقية للإلغاء والاستئناف والأولوية والقواعد والتفاصيل الكاملة.
- مصغرات الملفات المتاحة، ومعاينة محلية للرفع عندما يسمح المصدر، وأيقونات بديلة حسب النوع. لا تتحكم أخطاء المصغرة في نجاح النقل.
- الملف الذي يحفظ بيانات مكتبته يبقى في قسم Active؛ لا يُحوّل إلى مكتمل بصريًا. تختلف تسمية نجاح التحقق أو التصدير أو التنزيل عن نجاح الرفع.
- تستمر مهلة Telegram وشروط الشبكة والشحن والخزنة. إخفاء اسم الملف والخطأ والمصغرة عند قفل خزنته، ولا تُعرض مصغرة إصدار أحدث مكان إصدار المهمة.

## التحقق

الفحوص المسجلة في [TESTING.md](TESTING.md) تشمل إنشاء جميع متجهات Solar، وتوزيع كل حالات المهام دون تكرار، والأولوية وحدود اليوم، وفلاتر Activity وإجراءاتها، والخزنة المقفلة ومهلة الحساب، والعرض بعرض 320dp وخط 200%. معاينات Compose ببيانات تجريبية تُستخدم لمراجعة التخطيط، وليست قياسًا لسرعة الشبكة أو سلاسة هاتف حقيقي.

يبقى مفتاح التوقيع ومعرّف التطبيق وصيغة Telegram وإصلاحات الرفع من 0.10 كما هي. يتطلب نشر APK نجاح فحوص الجهاز والتوقيع والترقية في workflow.
